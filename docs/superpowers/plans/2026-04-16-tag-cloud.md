# Tag Cloud Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the flat tag cloud with a classic alphabetical Web 2.0-era cloud (sqrt-scaled size/opacity/weight, staggered fade-in, sticky filter input, A–Z ↔ count sort toggle), mobile-friendly and no-JS degradable.

**Architecture:** One Hugo taxonomy template (`terms.html`) does all the sizing math at build time and emits data attributes. A vanilla JS module wires the filter/sort controls. CSS styles live in `components.css`. Only the `/tags/` list template loads the JS. No server changes.

**Tech Stack:** Hugo (extended) templating, vanilla JS (ES2017+, no deps), CSS (custom properties + keyframes). Theme is a git submodule at `themes/sindrome/`.

## Task 2: Create `tag-cloud.js` (submodule)

**Files:**
- Create: `/home/vjt/code/sindro.me/themes/sindrome/assets/js/tag-cloud.js`

- [ ] **Step 1: Write the file**

Create `/home/vjt/code/sindro.me/themes/sindrome/assets/js/tag-cloud.js` with this exact content:

```javascript
(function () {
  const cloud = document.querySelector('.tag-cloud');
  if (!cloud) return;
  const filter = document.querySelector('.tag-filter-input');
  const sortBtn = document.querySelector('.tag-sort-btn');
  const empty = document.querySelector('.tag-cloud-empty');
  const items = Array.from(cloud.querySelectorAll('.tag-cloud-item'));

  if (filter) {
    filter.addEventListener('input', () => {
      const q = filter.value.trim().toLowerCase();
      let shown = 0;
      for (const el of items) {
        const match = el.dataset.name.includes(q);
        el.hidden = !match;
        if (match) shown++;
      }
      if (empty) empty.hidden = shown !== 0;
    });
  }

  if (sortBtn) {
    sortBtn.addEventListener('click', () => {
      const next = sortBtn.dataset.mode === 'alpha' ? 'count' : 'alpha';
      sortBtn.dataset.mode = next;
      sortBtn.textContent = next === 'alpha'
        ? sortBtn.dataset.labelAlpha
        : sortBtn.dataset.labelCount;
      const sorted = items.slice().sort((a, b) =>
        next === 'alpha'
          ? a.dataset.name.localeCompare(b.dataset.name)
          : parseInt(b.dataset.count, 10) - parseInt(a.dataset.count, 10)
      );
      for (const el of sorted) cloud.appendChild(el);
    });
  }
})();
```

## Task 3: Rewrite `terms.html` (submodule)

**Files:**
- Modify: `/home/vjt/code/sindro.me/themes/sindrome/layouts/_default/terms.html`

- [ ] **Step 1: Replace the entire file**

Overwrite `/home/vjt/code/sindro.me/themes/sindrome/layouts/_default/terms.html` with:

```go-html-template
{{ define "main" -}}
<div data-pagefind-ignore>
{{ partial "featured-image.html" . }}
<h1 class="title">{{ .Title }}</h1>

{{- /* Compute min/max post counts across all terms for scaling */ -}}
{{- $min := 0 -}}
{{- $max := 0 -}}
{{- range $i, $term := .Data.Terms.Alphabetical -}}
  {{- $c := len .Pages -}}
  {{- if or (eq $i 0) (lt $c $min) -}}{{- $min = $c -}}{{- end -}}
  {{- if gt $c $max -}}{{- $max = $c -}}{{- end -}}
{{- end -}}
{{- $range := cond (eq $max $min) 1 (sub $max $min) -}}

<div class="tag-filter-bar">
  <input type="search" class="tag-filter-input"
         placeholder="{{ i18n "tag_filter_placeholder" }}"
         autocomplete="off"
         aria-label="{{ i18n "tag_filter_placeholder" }}">
  <button type="button" class="tag-sort-btn"
          data-mode="alpha"
          data-label-alpha="{{ i18n "sort_alpha" }}"
          data-label-count="{{ i18n "sort_count" }}">
    {{ i18n "sort_alpha" }}
  </button>
</div>
<noscript><style>.tag-filter-bar{display:none}</style></noscript>

<div class="tag-cloud">
{{- range $i, $term := .Data.Terms.Alphabetical }}
  {{- $count := len .Pages -}}
  {{- $raw := div (float (sub $count $min)) (float $range) -}}
  {{- $t := math.Sqrt $raw -}}
  {{- $size := add 0.75 (mul $t 1.45) -}}
  {{- $opacity := add 0.55 (mul $t 0.45) -}}
  {{- $weight := int (add 400 (mul (math.Round (mul $raw 3.0)) 100)) -}}
  <a href="{{ .Page.RelPermalink }}"
     class="tag-cloud-item"
     data-name="{{ lower .Name }}"
     data-count="{{ $count }}"
     style="font-size:{{ printf "%.2f" $size }}rem;font-weight:{{ $weight }};opacity:{{ printf "%.2f" $opacity }};--anim-delay:{{ $i }};">
    {{- .Page.Title }}<sup>{{ $count }}</sup>
  </a>
{{- end }}
</div>
<p class="tag-cloud-empty" hidden>{{ i18n "tag_cloud_empty" }}</p>

{{- $tagCloudJs := resources.Get "js/tag-cloud.js" | minify | fingerprint }}
<script defer src="{{ $tagCloudJs.RelPermalink }}"></script>
</div>
{{ end }}
```

Notes:
- `.Name` on an `OrderedTaxonomyEntry` is the raw term key (e.g. `home-assistant`) — better for filter matches than the humanized title.
- `.Page.Title` remains the display label (may be humanized by Hugo or set in a term page's front matter).
- `$range := cond (eq $max $min) 1 (sub $max $min)` guards against divide-by-zero if all tags have equal counts.
- `int (…)` on the weight produces a clean integer for the `font-weight` property.
